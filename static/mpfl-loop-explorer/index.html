Radiation: Q = n_sides A ε σ (T_skin⁴ − T_sink⁴). Fluid rise: ΔT = Q / (ṁ cp). Charge: Psat + NPSH margin, with Psat typed here — not looked up from a brand table. Skin k is a slider (default 160 W/m·K), not a mill listing. Channel h uses Nu = 4.36 in laminar flow and a Dittus–Boelter estimate when turbulent. Conduction drop is a half-land spread through the sheet so the k slider moves T_skin. Mass is skins (two faces × geometry × sheet) + coolant in channels and flex + flex walls.
